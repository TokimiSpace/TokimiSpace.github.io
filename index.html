LLM PRIVACY / DATA MINIMIZATION

Bridge
Time

KIMI PRIVACY ENVELOPE · REFERENCE EXTRACTION

SUPPORTED ID → ALIAS / BLOCK → KIMI

BridgeTime Kimi 隱私封裝是由 private BridgeTime source snapshot 衍生並額外加固的參考實作，公開送往 LLM 之前的別名替換、最小化封包與出站檢查。截至 2026-08-25，正式站助理仍停用；這份開源參考不是 production deployment 證明。 BridgeTime Kimi Privacy is a hardened reference derived from a private BridgeTime source snapshot. It exposes pre-LLM alias replacement, a minimized outbound envelope, and egress checks. As of 2026-08-25, the production assistant remains disabled; this open reference is not evidence of a production deployment.

BridgeTime Kimi 隱私封裝邊界 BridgeTime Kimi privacy-envelope boundaries

  • HARDENED REFERENCE EXTRACTION
  • NOT PRODUCTION DEPLOYMENT EVIDENCE
  • PSEUDONYMIZATION · NOT ANONYMIZATION
  • OUTBOUND PAYLOAD TESTS

隱私邊界 Privacy boundary 別名處理可替換已知名單身分，以及受支援格式的電話與 Email，但抓不到所有敏感資料。日期、數量、狀態碼、時間區間、業務語意與 opaque tokens 仍可能傳給模型供應商。這是資料最小化與假名化層，不是匿名化、合規認證或零外洩保證。Kimi 名稱僅用於說明 API 相容性，不代表合作、認證或背書。 Aliasing replaces known roster identities and supported phone and email formats, but it cannot catch all sensitive data. Dates, counts, status codes, time ranges, business context, and opaque tokens may still reach the model provider. This is data minimization and pseudonymization—not anonymization, compliance certification, or a zero-leakage guarantee. The Kimi name identifies API compatibility only and does not imply affiliation, certification, or endorsement.

PUBLISHING PROTOCOL / 04

開源，不省略邊界。 Open, with the boundaries intact.

  1. A

    可驗證 Verifiable

    區分原始碼確認、建置確認、實機紀錄與未來規劃。 We distinguish source-confirmed, build-confirmed, historically observed, and planned work.

  2. B

    限制透明 Transparent limits

    公開已知問題，不把原型包裝成成品。 Known limitations stay visible; prototypes are not presented as finished products.

  3. C

    授權清楚 Clear licensing

    程式、硬體來源與文件依專案標示各自授權；品牌權利維持獨立。 Code, hardware source, and documentation carry scoped licenses; brand rights remain separate.
